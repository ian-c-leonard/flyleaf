# Plan

Keep this short. An assistant reads it at the start of every session.

## Goal

What you want to make, for whom, and by when. For example: a printed book
for the family by next December, and a private website the relatives can
sign in to.

## Priorities

In order. For example:

1. Get the tree clean and every direct ancestor sourced.
2. Write the stories for the four grandparents' lines.
3. Gather photographs from the relatives.

## Standing decisions

Choices the assistant should not ask about again. For example:

- Research budget: up to a set amount per session. The assistant proposes
  each purchase with what it would show; I pay.
- Living relatives: public-record facts only, unless they agree to more.
- The website stays private, behind sign-in.
