# Flyleaf documentation

## Getting started

- [Quick start](quick-start.md): install Flyleaf, bring in a tree, and build
  the book and the website.
- [From a tree to a finished book](journey.md): the whole process, start to
  finish, with a link to the guide for each step.

## Research

- [Research standards](research-standards.md): kinds of source, confidence,
  reading a record, citing it on the right fact, negative findings, the
  research log and saving sources.
- [Research playbook](research-playbook.md): how a research session runs,
  where records are found, when to stop, transcribing with AI, and working
  with several assistants.
- [Working with living relatives](relatives.md): questionnaires, interviews,
  family papers, citing family sources, and what to publish about the living.
- [Photographs and documents](photos-and-documents.md): scanning, file
  names, provenance, plates, captions, identifying people, and rights.

## Writing

- [Style guide](style-guide.md): the register, names, dates, places,
  citations, the stories, pictures, the index and front matter, following
  the NEHGS *Guide to Genealogical Writing*.
- [Writing the book](book.md): story files, citations, settings, and what
  the build checks.
- [Reviewing before you share or print](review.md): the claim audit,
  independent reviewers with prompts to paste, and readers.

## Publishing

- [Hosting the website](hosting.md): a public static site, or a private one

- [Lineage societies](lineage-societies.md): using a documented line for an
  application.
